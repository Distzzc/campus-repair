# AI 规范

读取时机：AI需求、提示词、模型调用和评测前。本文件当前只约束未来变更，本阶段无AI SDK/调用/向量检索/MCP，相关能力尚未实现，运行能力待后续验证。

| 强制规则 | 检查方法 / 缺陷判据 |
| --- | --- |
| 只提供可编辑描述草稿、分类建议和缺失信息提示，保留学生原文；不得编造原因、地点、处理结果 | 脱敏固定集逐项检查事实来源；新增无来源事实即缺陷 |
| AI不得自动提交、分配人员、改状态，用户确认编辑后才能走正常授权流程 | 检查模型工具权限与状态副作用；越过确认/权限即缺陷 |
| AI不可用仍可手动报修；超时、异常、格式/字段校验失败均回退人工 | 故障注入/超时/非法输出测试；人工入口不可用即缺陷 |
| 提示词、模型/参数、输出schema版本纳入版本管理；输入最小化，输出视为不可信，外部调用不得在DB事务内 | 审查版本、脱敏和事务边界；不可追溯/敏感内容外发/事务内调用即缺陷 |
| 引入AI前定义版本化脱敏评测集与验收阈值，覆盖幻觉、缺失信息、提示词注入、分类准确率、超时失败和人工回退 | 同一评测版本可重复运行并留证；无阈值/只看成功示例/未达阈值合入即缺陷 |

超时数值、评测规模与准确率阈值由AI独立变更在引入时明确，此阶段不虚构指标或通过结果。修改提示词、模型或schema必须重跑同一基线并比较回归。
