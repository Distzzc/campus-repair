# 安全规范

读取时机：配置、权限、表单、输出、附件、令牌和外部请求修改前。当前生效：输入校验、配置外置、日志和错误脱敏、运行数据排除。业务与外部调用条款后续适用，尚未实现/验证。

| 强制规则 | 检查方法 / 缺陷判据 |
| --- | --- |
| 环境白名单、必填及范围校验，禁止密钥硬编码；.env/数据库/上传/日志不入Git或构建上下文 | F03–F05、R06及历史扫描；真实敏感值提交/打包即缺陷 |
| 不公开路径/SQL/堆栈/敏感配置；日志禁密码、令牌、密钥、正文、位置、描述、原始URL及异常 | H05/H08多位置独特哨兵；任何哨兵外泄即缺陷 |
| 未来默认拒绝，逐资源逐动作授权；维修人员只能访问获派工单，学生只能访问本人记录 | 授权矩阵、跨用户/跨角色ID替换；任何越权即缺陷 |
| 附件继承工单权限，大小/类型/内容校验、随机安全文件名，禁止可执行内容及路径穿越 | 后续附件越权/伪造MIME/超限/穿越测试；绕过即缺陷 |
| 密码仅用受维护库Argon2id散列，参数按引入时权威安全基线评审；禁止明文/可逆存储 | 检查存储值、参数及登录测试；弱散列/明文/回显即缺陷 |
| 会话令牌用HttpOnly/Secure/SameSite Cookie；登录轮换、退出撤销、过期拒绝；状态修改防CSRF | Cookie、轮换、撤销、过期、CSRF测试；旧令牌继续授权即缺陷 |
| 前后端输入校验，参数化SQL；Jinja2默认转义，用户内容禁safe | SQL注入/XSS/边界测试；拼接输入SQL/未转义输出即缺陷 |
| 出站仅固定配置白名单HTTPS；拒绝回环/内网/链路本地/元数据IP；DNS和重定向每跳重新校验 | SSRF测试覆盖IPv4/IPv6/DNS重绑定/重定向；访问非允许地址即缺陷 |

当前没有登录功能，不要求无用途的SECRET_KEY。将来引入密钥时规定最小权限、轮换/撤销流程，不允许密钥进入提示词、日志或版本库。
